THE LOOP

主张 → 实验 → 证据 → 修正

智能体依据验收合同提出实验，在看到结果前登记假设与预测。工具运行 ngspice，计算增益误差、残差失真、相位与输出斜率。新观测返回模型，决定接下来的测量。

每次工具调用都经过数值范围与输入域检查。目标增益和验收阈值不会在运行中被修改。模型请求失败会明确停止，不会伪装成成功的大模型研究。

三个独立角色

  • 研究员：DeepSeek 原生工具调用，决定搜索实验。
  • 实验台：ngspice 47，执行公开网表。
  • 审查器：冻结的确定性指标和机制证据规则。
MODEL CARD

透明的通用行为模型

运放模型具有有限开环增益、单主极点、压摆率限制、输出摆幅与抗积分饱和。低通案例增加输入 RC 网络。它用于研究和教学，不代表具体商业器件、工艺角或真实测量。

残差失真 = 移除直流与基波后的残差 RMS / 基波 RMS。瞬态数据在最后四个周期内均匀重采样并拟合。此指标包含数值误差，与仅统计谐波的 THD 有区别。

工作域比例仅指固定对数网格的通过点比例；不等于连续面积或器件良率。机制记录表示观测或对照支持，不表示唯一因果证明。

DESIGN VALIDATION

候选改善也需要复测

在线模式由 DeepSeek 依据实验提出 GBW 与 SR 参数候选，保持目标增益、验收标准和输出摆幅。本地模式使用明确标注的固定候选。对原实验回归，并在独立网格检查有效范围变化。无法修复的饱和边界会保留。

候选模型还需要真实器件选择、功耗与稳定性验证才能进入工程设计。软件不会据此声称已完成芯片签核。

RESEARCH SOURCES

方法来源与自主实现

本作品自主实现实验编排、证据审查、工作域可视化与导出。研究启发包括：

  • LLM-Falsifier：带数值反馈的反例搜索。
  • LLM-IDEA：可辨识性与实验选择。
  • AnalogAgent：工具驱动的模拟电路设计。
  • ngspice：开源仿真执行器。

前沿方法启发不等于已复现其论文结果；作品实际效果以所附评测记录为准。
